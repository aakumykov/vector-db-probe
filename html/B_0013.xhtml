«Белая сажа» — мелкодисперсный аморфный порошок кремниевой кислоты белого цвета. Его производят из весьма доступной комплексной кислоты H2[SiF6], получающейся в качестве побочного продукта в ряде производств. Водный раствор этой кислоты обрабатывают аммиаком. Вначале образуется соль (NH4)2[SiF6], которая затем подвергается полному гидролизу в соответствии с уравнением

(NH4)2[SiF6] + 4NH3 + nН2О → 6NH4F + SiO2 • (n - 2)Н2О

В результате из раствора выделяется аморфный осадок кремниевой кислоты, который после высушивания превращается в мелкодисперсный белый порошок. Его производственники и называют «белой сажей». Она используется в качестве наполнителя резин взамен технического углерода (черной сажи). При введении в резиновую смесь красителей можно получать изделия различного цвета.
