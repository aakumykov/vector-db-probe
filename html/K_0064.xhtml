Коксовый газ. Получается при термической переработке угля в кокс без доступа воздуха. Его средний состав по основным компонентам (в % по объему) примерно следующий: H2 — 59,8; N2 — 2,9; СО — 6,8; CH4 — 25,3; C2H6 — 1,7; CnHm — 2,3; NH3 — 1,0; O2 — 0,3. Важное сырье для химической индустрии. Аммиак, например, перерабатывают на азотное удобрение — сульфат аммония (NH4)2SO4.
