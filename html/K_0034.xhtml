Керамзит — искусственный пористый керамический материал. Давно было замечено, что некоторые глины при быстром нагревании способны значительно увеличиваться в объеме. Как правило, таким свойством обладают сланцевые глины, содержащие углеродные вещества. При нагревании глин данные углеродные вещества сгорают с образованием CO2. Образующийся газ и приводит к вспучиванию массы и образованию пор.

Для производства керамзитов используют сырье, способное давать при высокой температуре (1100 — 1200°С) пластичную стеклообразную фазу. Ее вязкость должна быть настолько высока, чтобы не позволять образовавшимся газам удаляться.

Если исходный материал не содержит веществ, способных к газовыделению, то их вводят специально. К газообразующим веществам, пригодным для получения пористых керамических материалов, относят карбонат кальция:

CaCO3 → CaO + CO2

сульфат кальция (гипс или ангидрит):

2CaSO4 → 2СаО + 2SO2 + O2

Для этой же цели может быть использован пирит: ...

FeS2 → FeS + S (газ)

S (газ) + O2 → SO2

Особенно эффективным газообразующим свойством обладает смесь оксидов железа и угля:

Fe2O3 + С → 2FeO + СО

Fe2O3 + СО → 2FeO + CO2

Порообразующие вещества должны разлагаться в определенном температурном интервале. Если они разлагаются до образования пластичной стеклообразной массы, то  газ уходит из материала, не выполнив своей роли. При слишком высоких температурах уменьшается вязкость массы, что также будет способствовать удалению газа.
