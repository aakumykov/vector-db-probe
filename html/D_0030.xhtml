Дымовые завесы. Известны различные составы для создания дымовых завес. В частности, для этой цели используют жидкости TiCl4, SnCl4 и SiCl4. Тетрахлорид титана считается наилучшей. Дым образуется в результате гидролиза, например:

TiCl4 + 5H2O = Ti(OH)4∙H2O + 4HCl

Влага, необходимая для реакции, всегда присутствует в воздухе. Если одновременно с распылением этих жидкоcтей распылять водный раствор аммиака, то вследствие образования хлорида аммония дым усиливается:

NH3 + HCl = NH4Cl

Дымовые завесы также получают путем сжигания белого или красного фосфора:

4Р + 5О2 = 2P2O5

Оксид фосфора (V) жадно притягивает влагу с образованием фосфорных кислот. Это усиливает эффект дымообразования. Интенсивное дымообразование происходит в результате горения смеси порошка магния с гексахлорэтаном. Реакция описывается уравнением

3Mg + C2Cl6 = 2С + 3MgCl2
